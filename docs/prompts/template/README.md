# SPDD Prompt Templates

Use these prompts as the standard SPDD chain for OpenSpec implementation tasks.

Run them in order:

1. `01-requirements.md`
2. `02-entities.md`
3. `03-approach.md`
4. `04-structure.md`
5. `05-operations.md`
6. `06-norms.md`
7. `07-safeguards.md`

Each prompt maps to the SPDD REASONS canvas. Requirements, Entities, Approach, and Structure define the abstraction. Operations decomposes the abstraction into concrete work. Norms and Safeguards apply across the whole chain.
