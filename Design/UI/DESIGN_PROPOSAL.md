# Inspection UI requirements

Use the maintained [UI behavior](../../docs/simplified-ui-redesign-plan.md) and [system map](../../docs/system-map.md). Update those sources with implementation changes rather than maintaining a separate phase or epic plan.

The application uses MVC with coordinators and services, durable scoped JSON drafts, and queue/focus/review navigation from Team. Team switching is disabled; reset/history, rechecks and sticker eligibility are deferred requirements.
