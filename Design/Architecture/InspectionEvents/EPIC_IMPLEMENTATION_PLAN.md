# Inspection implementation scope

Use the maintained [active backlog](../../../openspec/changes/technical-inspection-event-development-plan/tasks.md). Update those sources with implementation changes rather than maintaining a separate phase or epic plan.

The application uses MVC with coordinators and services, durable scoped JSON drafts, and queue/focus/review navigation from Team. Team switching is disabled; reset/history, rechecks and sticker eligibility are deferred requirements.
